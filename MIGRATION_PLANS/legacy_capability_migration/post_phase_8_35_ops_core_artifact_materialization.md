# Post 8-35: Ops Core Artifact Materialization

## Status

Done.

## Goal

Persist successful core operations skill outputs as real workspace artifacts.

This keeps operations migration inside the new product framework instead of creating a separate operations document system.

## Backend Change

The existing `ops::execute` dispatch path now normalizes output contracts for core operations skills.

Successful output includes:

```text
status=success
has_data=true
adapter_status=manual_input
data_readiness=...
summary=...
```

When required user input is missing, output becomes:

```text
status=deferred
has_data=false
adapter_status=user_input_required
data_readiness=missing_user_input
summary=...
```

This prevents the frontend from presenting empty operations outputs as real deliverables.

## Workspace Artifact Change

`WorkspaceApi::materialize_agent_content_artifact` now supports:

- `ops_promo_planning` -> `artifactType=ops_promo_plan`
- `ops_pricing_strategy` -> `artifactType=ops_pricing_strategy`
- `ops_channel_strategy` -> `artifactType=ops_channel_strategy`
- `ops_inventory_planning` -> `artifactType=ops_inventory_plan`
- `ops_listing_copy` -> `artifactType=ops_listing_copy`
- `ops_assortment_planning` -> `artifactType=ops_assortment_plan`
- `ops_execution_plan` -> `artifactType=ops_execution_plan`

Artifacts are markdown, inline, generated by `agent_session`, and use:

```text
metadata.kind=agent_generated_content
metadata.contentCategory=ops
```

## API / SSE Contract

No new HTTP route was added.

The existing `workspace_artifact_created` SSE event is reused. `API_DOCS/app.md` and `API_DOCS/sse.md` document the ops artifact types and the deferred behavior when required input is missing.

## User-Visible Change

Users can ask the operations worker for promotion planning, pricing strategy, channel strategy, inventory planning, listing copy, assortment planning, or 30-day execution planning. When the backend succeeds, the output can appear in the workspace artifact list/detail/export flow.

If required input is missing, the backend returns `deferred` and does not create a fake operations artifact.
