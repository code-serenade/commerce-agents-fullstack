# Phase 12：创意内容类 Skill Native 迁移

## 本轮目标

以后端迁移为主，把旧产品创意岗位的内容生成能力迁入新产品 Agent skill runtime：

- 短视频脚本
- 种草文案
- IP 定位
- 内容排期
- 趋势捕捉
- 直播脚本
- 产品软文

这些能力不再只返回 `deferred` 骨架，而是先由 Rust 本地 native 规则生成结构化可用产物。

## 修改范围

- 产品内核：创意岗位从“标题评分为主”扩展为“可生成内容方案的虚拟员工”。
- 后端：修改 `backend/crates/agent/src/skills/creative.rs` 和 worker 自动补偿规则。
- API：不新增接口，沿用 Agent SSE。
- 前端：本阶段不改前端，复用现有 `skill_requested` / `skill_result` / 最终回答展示。

## 用户可感知变化

用户在问答页提出以下问题时，后端更容易直接调用对应创意 skill，并在过程区显示真实能力调用：

- “帮我写一个抖音短视频脚本”
- “生成小红书种草文案”
- “做品牌 IP 定位”
- “排一周内容日历”
- “写直播带货话术”
- “写一篇产品软文”
- “分析近期内容趋势方向”

结果不再只是提示“内容引擎未接入”，而会返回脚本结构、文案标题、正文骨架、话术阶段、排期安排、趋势方向和执行指标。

## 仍未完成

- 尚未接入外部搜索实时趋势数据。
- 尚未按真实商品 ID 自动读取商品详情注入 creative skill。
- 尚未生成图片、视频或 DOCX 文件，仅生成结构化文本产物。

## 验收口径

- Agent 单元测试覆盖 creative native skill 成功执行。
- Agent 单元测试覆盖 creative 自动补偿命中短视频、种草、IP、排期、趋势、直播、软文等意图。
- `cargo test -p agent` 通过。
