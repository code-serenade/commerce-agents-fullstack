# Post 8-130：问答上下文引用明细

## 目标

在 Post 8-129 的消息级上下文摘要基础上，继续让用户能查看本轮真实引用的商品和资料明细，同时保持默认界面清爽。

这个切片只消费前端发送时已有选择和历史消息里已保存的 ID/ref，不新增后端 API，不伪造名称。

## 变化

- `contextSummary` 增加 `products` 和 `sources` 引用明细。
- 新发送消息会保留当前已选商品名、品牌、平台、品类、状态和资料标题。
- 历史消息如果后端只保存 ID/ref，则只展示 ID/ref，不编造商品名或资料名。
- 消息上下文 UI 拆成独立 `MessageContextSummary` 组件。
- 摘要仍默认紧凑展示，商品/资料明细放入可展开区域，避免对话流继续拥挤。

## 产品影响

用户能在每条提问下确认：

- 本轮是否未选商品。
- 本轮如果选了商品，具体选的是哪些商品。
- 本轮如果引用资料，具体引用了哪些会话资料。

这进一步降低“普通问答误带商品上下文”或“指定商品链路不清楚”的体验风险。
