# Post 8-129：问答消息级后端上下文摘要

## 目标

把 Agent Chat 每条用户提问当时真实发送/保存的后端上下文展示出来，让用户能直接判断本轮是否引用了商品、资料、策略、岗位和模型。

这个切片只做前端对齐，不新增后端 API，不伪造商品或资料名称。

## 变化

- Agent Chat 消息模型新增 `contextSummary`。
- 新发送消息会从当前选择的商品、资料、策略、岗位和模型生成摘要。
- 历史消息会从后端已保存的 `contentJson.context` 和 `contentJson.strategy` 还原摘要。
- 用户消息下方新增紧凑 chip：
  - 未选商品 / 已选商品数量
  - 未选资料 / 已选资料数量
  - 回答策略
  - 主岗位和岗位数量
  - 模型名称

## 产品影响

用户在对话流里可以看到这次提问是否真的带了商品上下文。

如果没有手动选择商品，界面会显示“未选商品”，这和后端“未指定商品不注入默认商品”的规则保持一致。

如果历史消息只保存了商品 ID 或资料 ref，前端只展示数量，不编造商品名或资料名。
