# Post 8-36: Ops Advanced Artifact Materialization

## Status

Done.

## Goal

Persist successful advanced operations skill outputs as real workspace artifacts.

This continues the old-product skill migration inside the new product framework: Agent skill -> structured output contract -> workspace artifact -> existing frontend artifact/query/export paths.

## Backend Change

The existing `ops::execute` dispatch path now has clearer readiness disclosure for advanced operations skills.

Successful output includes:

```text
status=success
has_data=true
adapter_status=manual_input
data_readiness=user_provided | calculated_from_defaults
summary=...
```

Missing required user input remains:

```text
status=deferred
has_data=false
adapter_status=user_input_required
data_readiness=missing_user_input
summary=...
```

Specific rules:

- `ops_smart_pricing` succeeds when cost and current price are present; missing competitor prices are disclosed as `calculated_from_defaults`.
- `ops_inventory_optimizer` needs SKU rows and defers without them.
- `ops_ad_fatigue_detector` needs channel rows and defers without them.
- `ops_abc_xyz_classifier` can use deterministic demo SKUs and discloses them as `calculated_from_defaults`.

## Workspace Artifact Change

`WorkspaceApi::materialize_agent_content_artifact` now supports:

- `ops_smart_pricing` -> `artifactType=ops_smart_pricing_report`
- `ops_inventory_optimizer` -> `artifactType=ops_inventory_optimization_report`
- `ops_ad_fatigue_detector` -> `artifactType=ops_ad_fatigue_report`
- `ops_abc_xyz_classifier` -> `artifactType=ops_abc_xyz_report`

Artifacts are markdown, inline, generated by `agent_session`, and use:

```text
metadata.kind=agent_generated_content
metadata.contentCategory=ops
```

## API / SSE Contract

No new HTTP route was added.

The existing `workspace_artifact_created` SSE event is reused. `API_DOCS/app.md` and `API_DOCS/sse.md` document the advanced ops artifact types and the deferred behavior when required input is missing.

## User-Visible Change

Users can ask the operations worker for smart pricing, inventory optimization, ad fatigue detection, or ABC-XYZ inventory classification. When backend input is sufficient and the skill succeeds, the output can appear in the workspace artifact list/detail/export flow.

If SKU/channel/price input is missing where required, the backend returns `deferred` and does not create a fake advanced operations artifact.
