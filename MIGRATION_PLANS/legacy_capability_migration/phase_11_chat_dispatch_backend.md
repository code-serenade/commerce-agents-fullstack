# Phase 11：问答内核调度说明与轻问答兼容

## 本轮目标

以后端迁移为主，修复 Edge 对照旧产品暴露的问答内核差距：

- 短问答、确认类、调度说明类问题不应被复杂任务质量规则误判失败。
- “运营、数据、内容虚拟员工分工”应由后端任务图稳定支持，而不是只靠模型临场发挥。
- 中文产品应从后端提示词层约束中文输出，减少英文混入。

## 修改范围

- 后端 Agent 质量检查：`chat` 角色允许直接回答，不强制 `findings/recommendations`。
- 后端任务图配置：新增角色分工规则，稳定编排 `ops -> data/creative`。
- 后端提示词：强化 worker/chat 输出中文。
- 前端：本轮不新增 API，不主动扩前端，只复用现有 SSE 和任务图 UI。

## 用户可感知变化

用户在主问答里问“你能不能回答”“本轮哪些虚拟员工参与”“请按运营、数据、内容分工”时，产品应更稳定：

- 不再轻易显示 `quality completeness: no findings or recommendations` 这类后端失败。
- 角色分工类问题会更稳定出现运营、数据、内容创意的任务图。
- 输出应更偏中文，减少英文缺口问题。

## 仍未完成

- 外部搜索/RAG 适配器仍未真正接通。
- 平台执行、审批后重放、长任务异步执行仍是后续阶段。
- 旧产品问答入口的模型选择、导出、报告、附件等前端控制面未在本阶段迁移。

## 验收口径

- Agent 单元测试覆盖 chat 角色轻问答质量豁免。
- Agent 单元测试覆盖角色分工任务图规则。
- Edge 发送角色分工问题能触发 SSE 并输出任务图。
